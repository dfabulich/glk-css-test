# Glk CSS Basic Test

A visual test sample for Dannii’s [CSS Glk extension](https://curiousdannii.github.io/if/glk-proposals.html#css), exercising the “CSS Basic” property/value set discussed on the [intfiction.org thread](https://intfiction.org/t/glk-extension-proposal-css/66228).

## Build

```sh
./build.sh
```

Produces `csstest.gblorb` (Glulx storyfile wrapped for Blorb resources). Open it in a Glk interpreter and visually check each labeled sample.
